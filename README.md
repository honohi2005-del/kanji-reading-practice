# 漢字の読み｜ことばの練習帖

添付された教材画像の漢字語彙・読み・例文を、参考サイトの「教材を選ぶ → 一語ずつ答える」流れに合わせて整理した、依存関係のない静的 Web アプリです。

## 収録内容

- 紅・葉・黄・頂・美・船・飛・似・呼・結・果・封・法・各・位・異・移・務・更・越・郊・周・畑の23グループ
- 画像内の読み分けを含む72練習項目
- 「語彙 → 読み」「読み → 語彙」の2方向
- 教材順／シャッフル、例文表示、前後移動、自己評価
- 学習状況の `localStorage` 保存
- PC・タブレット・スマートフォン対応

## ローカル確認

`dist` を静的サーバーで配信します。

```powershell
py -3 -m http.server 4173 --directory .\dist
```

ブラウザで `http://localhost:4173/` を開いてください。

教材画像にない意味説明は追加せず、画像に例文がない語彙には学習用の例文を補っています。画像中の見出し・例文は練習対象の教材データとして扱っています。
